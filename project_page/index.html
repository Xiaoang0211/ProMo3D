02 / Probing-based motion distillation

Method overview

PMD tests motion-state decodability through a low-rank pairwise probe. Backbone features remain frozen throughout probe training.

→→→
01

Frozen geometric features

An input frame group supplies temporal or multi-view context. PMD uses the target frame's spatial tokens from predefined intermediate blocks.

Only the probe is learned. Pairwise same-state compatibility with a fixed reference token becomes a dense dynamic score map. Scores are reshaped, bilinearly upsampled, and binarized.

Coarse and refined are separate. SAM2 is an optional external mask-refinement stage. Motion decoding is evaluated before refinement.

03 / Empirical analysis

Representation analysis

Layer-wise probing, PCA of the probe-induced representation, and training-video ablations characterize motion decodability and data efficiency.

PCA here visualizes the supervised probe-induced subspace. PMD recovers motion-relevant information; semantic leakage remains a documented limitation.

04 / Experimental protocol

Reproducibility

Bash entrypoints cover environment setup, token export, probe training, coarse-mask inference, refinement, and evaluation. Code release is pending.

Pi3X / end-to-end
bash scripts/main/run.sh export pi3x
bash scripts/main/run.sh train pi3x
bash scripts/main/run.sh masks pi3x
bash scripts/main/run.sh refine pi3x
bash scripts/main/run.sh eval pi3x

Token export and dense inference

Exported tokens prepare probe training and token-level evaluation. Mask inference runs the frozen backbone on images and decodes the full target-frame token grid; sampled test exports are not required.

Benchmark transfer covers DAVIS, SegTrackv2, and FBMS-59, with no target-benchmark fine-tuning.
