# ProMo3D wordmark

`promo3d.svg` uses outlined Manrope ExtraBold glyphs, matching the project page's wordmark. ProMo is near-black (`#252525`) and 3D is blue (`#1F77B4`). It contains no embedded raster images or external font dependencies.

Manrope is distributed under the [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt).

`links/` contains uniformly sized SVG resource links with outlined Manrope labels. Logos come from the [NeurIPS media kit](https://neurips.cc/public/MediaKit), the ProMo3D wordmark above, [arXiv](https://info.arxiv.org/assets/arxiv-logo-one-color-black.svg), and [Hugging Face](https://huggingface.co/brand). Logo proportions and colors are preserved.
